HMD와 사용 방식, GPU는 어떤 관계일까?

PC에서 VR을 실행하는 PCVR과 헤드셋에서 바로 실행하는 Standalone에 각각 얼마나 시간을 쓰는지 물었습니다. 148명 중 PCVR 우세 115명(77.7%), 비슷하게 사용 14명(9.5%), Standalone 우세 19명(12.8%)입니다. 그래프에서 기종별로 볼 수 있습니다.
